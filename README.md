# 智投罗盘 · A股智能研判平台

> 面向 A 股个人投资者的本地化智能研判平台。先看清市场方向，再落到个股，最后用可解释的规则选股，并由大模型给出结构化点评。所有行情数据来自公开接口，实时计算、可追溯。

## 一、产品介绍

「智投罗盘」是一个**零依赖、本地优先**的 A 股智能研判工具。它把"看市场 → 看个股 → 选股票 → 问 AI"这一整套投研流程整合在一个单页应用里，所有计算都在本地完成，不依赖任何第三方 Python 包，也不需要 Node.js 构建。

### 核心能力

| 模块 | 解决的问题 | 关键内容 |
|---|---|---|
| **市场总览** | 今天市场能不能做、做什么方向 | 五大指数近40日走势、情绪温度（0–100）、涨跌家数结构、涨停梯队与封板率、行业/概念板块资金流向、板块涨幅榜、涨停个股、AI 市场研判 |
| **个股分析** | 这只票现在处于什么阶段 | 实时行情、K线(日/周/月，含 MA/MACD/量能)、分时图、趋势评分、**主力行为识别**（吸筹/洗盘/拉升/出货/震荡）、资金流向、相对大盘强弱、涨停档案、龙虎榜、AI 综合点评 |
| **智能选股** | 帮我找出符合形态的票 | **15 个内置策略**（含量化/机构方法）+ 自定义多因子条件，扫描成交额活跃股，逐只真实计算指标并给出命中说明，支持中途取消、结果排序与导出 CSV |
| **自选股** | 跟踪我关心的票 | 本地保存、批量刷新实时行情，点击进入个股分析 |
| **AI 投研助手** | 实时提问、解读数据 | 右下角悬浮按钮，多轮对话，自动注入当前页面实时数据快照，思考过程可折叠 |

### 内置选股策略（15 个）

按方法学分为四类：

**趋势跟踪（4 个）**
- 趋势多头：连续3日站上MA5 + MACD柱>0 + EMA12>EMA50
- MACD金叉：近3日 DIF 上穿 DEA 且站上 MA20
- 突破新高：收盘突破60日新高 + 放量1.3倍 + 涨幅≥2.5%（欧奈尔 CANSLIM 的 N）
- 强势回踩：60日涨幅≥15% + 近3日缩量 + 站稳MA20

**量价形态（4 个）**
- 首板洗盘：近1个月首板涨停后缩量洗盘，回撤未破MA20
- 低位放量：60日区间下40%分位 + 放量1.8倍 + 换手≥2.5%
- 跳空不回补：向上跳空缺口守住 + 当日再涨
- 地量见底：低位地量后首次放量收阳

**反转回归（3 个）**
- 涨停回马枪：近10日涨停 + 回调至MA10获支撑 + 当日红盘
- RSI 超跌反转：RSI6≤32 + 收阳 + 距高点回撤≥12%
- 布林下轨支撑：触及下轨 + 收阳 + 缩量

**量化 / 机构（4 个）**
- VCP 波动收缩：三段振幅逐级收窄 + 量能萎缩 + 贴近高点（Minervini 方法）
- 均线粘合待突破：MA5/10/20/60 极差≤3.5% + 量能抬头
- 低波动动量：60日涨8~80% + 日波动率≤3.2%（低波动异象）
- **多因子综合评分**：动量30% + 趋势25% + 量能20% + 低波15% + 位置10%，横截面百分位排名

### 交互体验

- 所有图表（K线、分时、走势线、柱状、横条、仪表盘）均支持**鼠标悬停**：十字光标 + 数值浮层 + 高亮
- 指数卡显示当前价在今日高低区间的位置条
- 统计块带 hover 说明（如"封板率 = 封板数 /（封板数 + 炸板数）"）
- AI 流式输出：思考过程实时显示、可折叠，正文逐字出现带光标

## 二、快速开始

### 环境要求

- **Python 3.8+**（仅标准库，无需 `pip install` 任何东西）
- 现代浏览器（Chrome / Edge / Safari）

### 启动

```bash
git clone https://github.com/<你的用户名>/zhitou-luopan.git
cd zhitou-luopan
./run.sh
```

打开 http://127.0.0.1:8710

### 配置 AI 模型 Key

AI 功能（市场研判、个股点评、选股解读、投研助手）需要火山引擎方舟的 API Key。通过以下任一方式提供（优先级从高到低）：

1. 环境变量：
   ```bash
   export ARK_API_KEY=你的key
   ```
2. 上一级目录的 `apikey` 文件（本地开发默认）：
   ```bash
   echo "你的key" > ../apikey
   ```

> 没有 Key 也能正常使用所有行情、图表、选股功能，只是 AI 相关按钮不可用。

## 三、使用指南

### 1. 市场总览

打开后默认进入市场总览。你会看到：

- **五大指数卡**：上证、深证、创业板、科创50、中证500，每张卡显示点位、涨跌幅、今日高低、近40日走势线（鼠标悬停可看每日点位）
- **情绪温度仪表盘**：0–100 分，越高代表短线做多意愿越强
- **涨跌结构**：上涨/下跌家数、涨超5%/跌超5%家数
- **涨停梯队**：1板/2板/3板/4板家数分布，最高连板高度
- **板块资金流向**：行业/概念切换，净流入/净流出排名
- **行业板块涨幅榜** + **涨停个股列表**

点击右上角「AI 市场研判」，模型会结合以上数据给出当日方向判断（约需 1–4 分钟）。

### 2. 个股分析

在顶部搜索框输入股票代码（如 `600519`）、名称（如 `贵州茅台`）或拼音（如 `gzmt`），按回车。

个股页包含：
- **Hero 区**：实时价格、涨跌幅、今开/最高/最低/昨收、成交额、换手率、量比、振幅、市值、PE、PB、涨停/跌停价
- **K线图**：日线/周线/月线切换，含 MA5/10/20/60、MACD、成交量，鼠标悬停显示当日 OHLCV 与均线数值
- **分时图**：当日价格走势 + 均价线 + 分时量能
- **趋势评分仪表盘**：0–100 分，附近5/20/60日涨幅、支撑位、压力位
- **主力行为识别**：吸筹/洗盘/拉升/出货/震荡，附命中信号明细
- **技术指标**：MA/EMA/MACD/KDJ/RSI/BOLL/ATR 全量数值
- **资金流向**：近40日每日净流入柱状图
- **相对大盘强弱**：个股 vs 上证 5/20/60日对比
- **涨停档案** + **龙虎榜**

点击「生成 AI 点评」获取模型综合研判。

### 3. 智能选股

1. 选择一个策略（按类别分组展示，量化类带紫色标签）
2. 点击策略卡片查看方法依据与规则
3. 选择候选池规模（200/400/600/800）
4. 点击「开始选股」，实时显示进度
5. 结果表格支持点击表头排序，点击行进入个股分析
6. 可导出 CSV，或点击「AI 解读结果」让模型分析命中特征

「自定义条件」允许你自己组合涨跌幅、换手率、量比、市值、PE、均线、MACD 等因子。

### 4. AI 投研助手

点击右下角「✦ AI 助手」按钮，从右侧滑出对话面板。

- **快捷问题**：根据当前页面自动生成（如在个股页会问"XX 的技术面怎么解读"）
- **多轮对话**：保留最近上下文，可以追问
- **页面感知**：你在个股页提问时，模型自动带上该股实时数据；在市场页时带上市场快照
- **停止生成**：生成中点击发送按钮（变红方块）即可中断
- **清空对话**：点击头部「清空」按钮

### 5. 自选股

在个股页点击「☆ 加自选」，自选股页会显示所有自选股的实时行情卡片。

## 五、数据源说明

东方财富 `push2*` 系列接口对非浏览器客户端有风控（会直接断连），因此策略是：

| 用途 | 采用数据源 |
|---|---|
| 实时行情、批量报价、搜索 | 腾讯 `qt.gtimg.cn` / `smartbox.gtimg.cn` |
| 日/周/月 K 线 | 腾讯 `web.ifzq.gtimg.cn` → 腾讯代理域名 → 新浪（多源兜底，长周期用日线聚合） |
| 个股资金流、板块资金流 | 新浪 `vip.stock.finance.sina.com.cn` |
| 全市场快照（涨跌家数） | 新浪 `Market_Center.getHQNodeData` |
| 涨停/跌停/炸板池 | 东方财富 `push2ex.eastmoney.com` |
| 龙虎榜 | 东方财富 `datacenter-web.eastmoney.com` |

由于上游限流，`net.throttle()` 对同类请求做全局串行限速（K 线约 8 次/秒），配合 TTL 缓存与"单飞"（同 key 并发只回源一次），400 只候选池选股约 60–90 秒。

## 六、AI 接入

- **模型**：`doubao-seed-evolving`（火山引擎方舟，OpenAI 兼容协议）
- **接口**：
  - `POST /api/ai/stream`：市场/个股/选股三个场景的结构化研判
  - `POST /api/chat/stream`：多轮对话投研助手
- **深度思考型模型特性**：会先输出大段 `reasoning_content`（思考过程），再输出正文。前端将其分为"模型深度思考中（可折叠）"与"分析正文"两块，避免长时间无反馈。正文通常需 1–4 分钟，属正常现象。
- **提示词**：见 `server/prompts.py`，均强制：只依据给定数据、不得编造、不引用未提供的信息面、必须给出风险提示与免责声明。

## 七、迁移到云服务器

代码已按"可平迁"设计，迁移时只需：

1. **密钥**：改为环境变量注入，不要上传 `apikey` 文件
   ```bash
   export ARK_API_KEY=xxxxx
   ```
2. **监听**：`HOST=0.0.0.0`（本地默认 `127.0.0.1`）
3. **部署方式**（任选）：
   ```bash
   # 方式一：直接跑
   HOST=0.0.0.0 PORT=8710 ARK_API_KEY=xxx python3 -m server.main

   # 方式二：容器
   docker build -t zhitou-luopan .
   docker run -d -p 8710:8710 -e ARK_API_KEY=xxx --name zhitou zhitou-luopan
   ```
4. **可选增强**（单机内存态的限制点，按需替换）：
   - 选股任务队列 `_jobs`：多实例部署时换成 Redis / 消息队列
   - TTL 缓存 `net.cache`：多实例时换成 Redis
   - 出网受限时设置 `ZHITOU_PROXY`

全部环境变量见 `.env.example`。
